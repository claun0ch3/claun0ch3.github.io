## Proyectos Destacados

### [MauiEmpresaApi](https://github.com/claun0ch3/MauiEmpresaApi)

Una solución integral distribuida que conecta movilidad y servicios backend.

* **Frontend:** Aplicación móvil multiplataforma en **.NET MAUI** que funciona en Android, iOS, Windows y macOS.
* **Arquitectura:** Implementación completa del patrón **MVVM** con separación clara de responsabilidades.
* **Consumo de API:** Integración asíncrona con servicios REST mediante HttpClient.
* **Características:** Dashboard interactivo, gestión de empleados CRUD, sincronización en tiempo real y diseño adaptativo.
* **Tecnologías:** .NET MAUI, C#, XAML, MVVM, REST API, Async/Await

### [DirectorioEmpleadosAPI](https://github.com/claun0ch3/DirectorioEmpleadosAPI)

Backend API REST robusto para gestión de directorio de empleados.

* **Desarrollo Backend:** API construida en **Python** con **Flask** que gestiona la lógica empresarial.
* **Base de Datos:** Persistencia con **SQLite** para almacenamiento de datos estructurados.
* **Containerización:** Proyecto completamente **dockerizado** con Docker Compose para despliegue sencillo.
* **Endpoints:** CRUD completo (Create, Read, Update, Delete) para gestión de empleados.
* **Tecnologías:** Python, Flask, SQLite, Docker, Docker Compose, REST API

### [Portfolio_Clau](https://github.com/claun0ch3/Portfolio_Clau)

Portfolio web personal con diseño moderno y responsive.

* **Frontend Web:** Sitio web profesional con énfasis en diseño responsive y experiencia de usuario.
* **Diseño:** Interfaz moderna, limpia y adaptativa para diferentes dispositivos.
* **Características:** Showcase de proyectos, sección de habilidades y formulario de contacto.
* **Tecnologías:** HTML5, CSS3, JavaScript, Responsive Design

### [Practica-firebase-retrofit-gestos](https://github.com/claun0ch3/Practica-firebase-retrofit-gestos)

Aplicación Android con integración de servicios modernos y gestos avanzados.

* **Backend as a Service:** Integración con **Firebase** para autenticación de usuarios y base de datos en tiempo real.
* **Consumo de APIs:** Uso de **Retrofit** para comunicación HTTP con servicios REST externos.
* **Interacción Avanzada:** Implementación de detección y manejo de **gestos táctiles** personalizados.
* **Arquitectura:** Aplicación del patrón **MVVM** en entorno Android para código mantenible.
* **Tecnologías:** Android, Java/Kotlin, Firebase, Retrofit, Gestures API, MVVM
